# 创作需求文档

## 核心层

- **体裁类型**（可主类型 + 次类型融合）：
  - 主类型：玄幻
  - 次类型 / 融合元素：悬疑怪谈 + 规则推理
- **核心创意与卖点（含金手指/外挂设定）**：
  - 一句话故事（logline）：夜巡灯官发现城中每盏长明灯对应一个活人的命数，灯灭人亡；他必须赶在自己那盏灯熄灭之前，查明究竟是谁在一盏一盏掐灭全城的灯。
  - 核心卖点 / 爽点钩子（读者冲着什么来：爽感来源 / 情绪钩子 / 新鲜感）：
    - 爽感：规则层层破解——每条怪谈规则看似无解，主角用推理找到规则的缝隙反杀
    - 钩子：每盏被掐灭的灯背后都是一桩人心罪案，凶手画像逐步反转
    - 新鲜感：把「灯与命数」做成都市怪谈的核心规则体系，区别于常见修宗门打怪
  - 金手指 / 外挂设定：
    - 来源 / 触发条件：沈观澜接任灯官当夜，误触祖传「引魂灯」被灯油溅伤，自此开了「灯视」
    - 核心能力 / 边界（能做什么、不能做什么）：
      - 能：看见每个人头顶「命灯」的焰色（健康、灾祸、将死之人的焰色不同）
      - 能：触碰熄灭的命灯，回溯死者临终前一刻的记忆片段（不完整，只有感官碎片）
      - 不能：无法点亮已灭之灯救回死者（死不可逆，强化悬疑张力）
      - 不能：看不出凶手的身份，只能看到凶案留下的「灯痕」线索
    - 代价 / 限制（避免无敌，平衡点在哪）：每次回溯会烧掉自己的一段记忆（从最不重要的开始，但用量失控就开始烧重要记忆）；灯视在白昼失效
    - 成长 / 演化路径（如何升级或转向）：从只能看焰色 → 读灯痕 → 回溯记忆 → 最终能「入灯」与将死之人的意识对话，代价也逐级加重
- **篇幅档位**（≤20 / 21-50 / 51-90 / 91-130 / 131-170 / 171-200 章）：51-90章
- **目标配比**（主线 / 支线 / 角色线 / 暗线）：主线4 / 支线1 / 角色线2 / 暗线3

## 设定层

- **世界观倾向**：
  - 时空 / 时代背景：架空古代州府「照夜城」，前朝遗留的城隍灯政体系仍在运转。
  - 独特质感 / 差异化卖点（这个世界与同类作品最大的不同）：不靠修炼升级，靠「规则理解深度」变强；每条怪谈规则都是可推理的谜题而非战力碾压。
  - （灯政体系细则、怪谈规则集、社会结构、配反派与关系网等世界细节由创作者自行设计补全，须与上述给定内核自洽。）
- **主角设定倾向**：
  - 身份与起点处境：沈观澜，22 岁，灯官衙门末等小吏，替死人值夜班（「长夜灯官」是没人愿接的凶差）
  - 核心欲望（最想要什么）：查清恩师（前任灯官）之死真相——他是唯一知道恩师的灯是「被人从城里熄灭的」的人
  - 核心恐惧 / 弱点 / 软肋：恐惧遗忘——回溯代价正在烧掉他的记忆，他怕有天忘了自己为什么要查下去
  - 人物弧光方向（起点 → 终点：从什么样的人变成什么样的人）：从「替死人值夜、只想安稳度日的小吏」→「明知点灯救不了所有人、仍选择为将死者留一盏证词之灯的守夜人」
  - 初始能力 / 资源定位（开局强弱、起跑线在哪）：无修为、有灯视；优势是灯官身份能出入命案现场，劣势是衙门内没人信他的「怪谈」

## 风格层

- **叙事风格基调**：冷峻克制、悬念前置；怪谈氛围靠细节压迫而非血浆堆砌。

## 承诺点（不可漂移项）

1. 主类型为玄幻、悬疑怪谈 + 规则推理；核心谜题「谁在掐灭全城的灯」贯穿主线，凶手身份须有伏笔可回溯。
2. 金手指「灯视」内核不得替换：看命灯焰色、触碰熄灭之灯回溯死者临终记忆碎片；看不出凶手身份，只能看到灯痕线索。
3. 金手指边界必须保留：无法点亮已灭之灯救回死者（死不可逆）。
4. 金手指代价必须保留：每次回溯烧掉自己一段记忆；灯视白昼失效。
5. 主角设定：沈观澜，灯官衙门末等小吏、替死人值夜班；核心欲望是查清恩师之死真相。
6. 主角弧光：从「只想安稳度日的小吏」成长为「为将死者留一盏证词之灯的守夜人」。
7. 世界观基调：靠「规则理解深度」变强的都市怪谈，不引入修炼升级体系。
8. 结构约束：篇幅 51-90 章；配比主线4 / 支线1 / 角色线2 / 暗线3；冷峻克制的悬疑基调。
