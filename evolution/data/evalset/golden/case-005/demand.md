# 创作需求文档

## 核心层

- **体裁类型**（可主类型 + 次类型融合）：
  - 主类型：玄幻
  - 次类型 / 融合元素：大女主复仇 + 丹道修炼
- **核心创意与卖点（含金手指/外挂设定）**：
  - 一句话故事（logline）：被炼丹世家当作「药人」养大的孤女，发现自己百毒不侵的体质正是失传千年的丹道圣体——仇家拿她试毒炼丹，她便以仇家的毒，炼自己的道。
  - 核心卖点 / 爽点钩子（读者冲着什么来：爽感来源 / 情绪钩子 / 新鲜感）：
    - 爽感：仇家引以为傲的毒丹，成了她的养料——「你炼的毒，我炼成丹」的逆向碾压
    - 钩子：药庐里一同长大的同伴是真棋子还是真姐妹，身份逐步反转
    - 新鲜感：金手指与诅咒同体——毒即力量、力量即倒计时，与传统吞噬流体质拉开差异
  - 金手指 / 外挂设定：
    - 来源 / 触发条件：姜蘅生来「丹骨」——骨髓能炼化毒物为丹力；十五岁那年吞下本该致死的「九转蚀心散」不死，才被老丹师点破体质
    - 核心能力 / 边界（能做什么、不能做什么）：
      - 能：炼化毒物为「丹力」反哺肉身与神魂，毒性越烈炼出的丹力越纯
      - 能：将炼熟的毒重新配制后外放（以彼之道还施彼身）
      - 不能：无法炼化「无毒之物」——她的修炼资源只有毒，旁人避之不及她必须主动涉险
      - 不能：压制不了「毒蛊」积累（见代价）
    - 代价 / 限制（避免无敌，平衡点在哪）：每炼化一分毒，体内「毒蛊」积累一分；毒蛊满溢会反噬神智入狂——她必须定期寻找「至纯之物」（稀有灵药或他人丹力）中和，越强越接近深渊
    - 成长 / 演化路径（如何升级或转向）：从被动炼毒保命 → 主动猎毒修行 → 以毒入丹自创「噬毒丹经」 → 终局领悟「毒丹同源」，把诅咒本身炼成大道
- **篇幅档位**（≤20 / 21-50 / 51-90 / 91-130 / 131-170 / 171-200 章）：91-130章
- **目标配比**（主线 / 支线 / 角色线 / 暗线）：主线4 / 支线2 / 角色线3 / 暗线1

## 设定层

- **世界观倾向**：
  - 时空 / 时代背景：架空修真界「九泉洲」，丹道为尊、剑道式微的時代
  - 核心设定（力量体系 / 社会结构 / 科技水平 / 规则法则，按体裁取舍）：
    - 丹道品阶：药童→药师→丹师→大丹师→丹尊→丹圣，每一阶需「丹火淬骨」
    - 药人制度：世家豢养体质特殊者试毒配药，地位不如药田灵兽——丹骨是传说中万中无一的「活鼎」
    - 社会结构：以「姜氏药庐」为首的四大丹道世家把持丹方，散修求丹如求命
    - 规则法则：丹力本质是「炼化外物为己用」；毒与药同源，差在剂量与炼法——全书力量体系的公理
  - 独特质感 / 差异化卖点（这个世界与同类作品最大的不同）：修炼资源是「毒」——别人下副本夺宝，她下毒渊猎毒；世界的丹道繁荣建立在药人血泪上，复仇线与世界批判同构
- **主角设定倾向**：
  - 身份与起点处境：姜蘅，17 岁，姜氏药庐编号「柒拾叁」的药人，自记事起每日试毒三次
  - 核心欲望（最想要什么）：两层递进——前期：带药庐的妹妹「阿萝」逃出生天；后期：毁掉药人制度本身（从私仇到公义）
  - 核心恐惧 / 弱点 / 软肋：恐惧自己在毒蛊反噬中变成「没有痛觉、只知猎毒的怪物」——她见过前一个丹骨的下场
  - 人物弧光方向（起点 → 终点：从什么样的人变成什么样的人）：从「忍痛求生、只求带着妹妹逃走的药人」→「明白逃无可逃、亲手炼碎药人制度的一代丹圣」
  - 初始能力 / 资源定位（开局强弱、起跑线在哪）：无修为、丹骨初醒；优势是百毒不侵与对毒的直觉，劣势是无功法、无靠山、体质秘密一旦暴露就是全世家的猎物
- **配角与关系网倾向**：
  - 关键配角原型（盟友 / 对手 / 导师 / 情感线 / 反派等功能位）：
    - 盟友：药庐杂役「阿萝」（真假身份是中期最大反转之一）
    - 导师：隐居的废丹师「乌老」，因反对药人制度被逐出世家，教她「毒丹同源」之道
    - 对手：姜家家主「姜鹤年」，丹道宗师、药人制度最坚定的维护者，并非纯恶——他真心认为药人制度「以少数换多数」
    - 反派：幕后「收丹骨」的神秘丹尊（终局真相：历代丹骨都被他炼成了本命丹）
    - 情感线：游侠剑修「裴照」（患「寒毒」需她的丹力续命，两人互为解药与软肋）
  - 核心关系张力（哪些关系是冲突或羁绊的来源）：姜蘅与阿萝「相依为命 vs 身份谜团」；与姜鹤年「私仇 vs 制度之辩」；与裴照「互救命门、互相牵制」；与乌老「传承与告别」

## 风格层

- **叙事风格基调**：外冷内烈，痛感写实；爽点来自逆向碾压与身份反转，不靠无脑打脸
- **视角与节奏**：女主单视角；复仇节点间隔「猎毒修行」段落，张弛交替
- **禁忌与红线**：女主不得无代价开挂（每次炼毒必有毒蛊积累的描写或交代）；复仇不靠敌人降智
