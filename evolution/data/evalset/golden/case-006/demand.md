# 创作需求文档

## 核心层

- **体裁类型**（可主类型 + 次类型融合）：
  - 主类型：玄幻
  - 次类型 / 融合元素：无限流（多副本）+ 元叙事
- **核心创意与卖点（含金手指/外挂设定）**：
  - 一句话故事（logline）：落魄说书人被卷入「话本世界」，每进入一个故事就必须扮演其中角色、改写悲剧结局才能活着出来——而他渐渐发现，所有话本背后共用同一个执笔人，那人正在写他的结局。
  - 核心卖点 / 爽点钩子（读者冲着什么来：爽感来源 / 情绪钩子 / 新鲜感）：
    - 爽感：熟知套路的资深读者视角碾压——主角一眼看穿话本套路，用「讲故事的规矩」反过来操控剧情
    - 钩子：每个副本是独立题材故事（武侠悲歌、志怪孽缘、宫廷倾轧），题材本身即新鲜感来源
    - 元叙事悬念：话本里反复出现的「白袖执笔人」是谁？为什么每个悲剧结局都在暗示主角的身世？
  - 金手指 / 外挂设定：
    - 来源 / 触发条件：柳敬亭说书十年，某夜说了半支祖传的「无尾话本」，当夜被卷入其中
    - 核心能力 / 边界（能做什么、不能做什么）：
      - 能：「叙事视界」——看见话本世界悬空的情节线与角色命运轨迹（谁是将死之人、哪条路通向悲剧结局）
      - 能：以「说书人规矩」干预剧情——在关键情节点「报幕」「插科打诨」，小幅扭转既定走向
      - 不能：直接改写结局（结局由话本「文心」锁定，只能通过改变通往结局的因果链达成）
      - 不能：在话本内使用话本世界观之外的力量（他在武侠副本里不会法术）
    - 代价 / 限制（避免无敌，平衡点在哪）：每次窥视情节线累积「入戏度」——入戏太深会忘记自己是谁、把扮演的角色当成真我；改写结局失败会被话本「合页」吞噬
    - 成长 / 演化路径（如何升级或转向）：从被动扮演角色 → 主动选择角色 → 与其他「书中人」结盟 → 终局拿到笔，从「书中人」变成「执笔人」
- **篇幅档位**（≤20 / 21-50 / 51-90 / 91-130 / 131-170 / 171-200 章）：91-130章
- **目标配比**（主线 / 支线 / 角色线 / 暗线）：主线4 / 支线3 / 角色线2 / 暗线2

## 设定层

- **世界观倾向**：
  - 时空 / 时代背景：现实层为架空古代市井「瓦舍勾栏」；故事层为「千话本世界」——每个话本是一个完整小世界。
  - 独特质感 / 差异化卖点（这个世界与同类作品最大的不同）：无限流的副本不是恐怖求生，而是「文学题材」本身——武侠、志怪、宫斗、农耕各具美感；力量来自叙事学（情节感、动机链、读者视角）而非斗气魔法。
  - （话本法则细则、书肆社会结构、配角群像与各副本题材由创作者自行设计补全，须与上述给定内核自洽。）
- **主角设定倾向**：
  - 身份与起点处境：柳敬亭，26 岁，茶楼末流说书人，祖传一部缺了结尾的残本，说得动人也活得潦倒
  - 核心欲望（最想要什么）：出去——回到自己的世界补上那支残本的结尾；后期转为：查清祖传残本与「执笔人」的关系，自己拿笔
  - 核心恐惧 / 弱点 / 软肋：恐惧「入戏」——他见过书肆里把角色当真名的疯子；而他的入戏度涨得比别人都快（因为他共情能力强，这是天赋也是诅咒）
  - 初始能力 / 资源定位（开局强弱、起跑线在哪）：无武力；优势是叙事视界与十年书目积累（识别套路的直觉），劣势是肉体凡胎、副本里的暴力冲突基本垫底

## 风格层

- **叙事风格基调**：每个副本切换对应文体的语言质感（武侠副本用白描短句、志怪副本用笔记体），现实层用市井烟火气。

## 承诺点（不可漂移项）

1. 主类型为玄幻、无限流（多副本）+ 元叙事；核心悬念「所有话本共用同一个执笔人，那人正在写主角的结局」贯穿主线。
2. 金手指「叙事视界 + 说书人规矩」内核不得替换：看见情节线与命运轨迹、在关键节点小幅干预剧情。
3. 金手指边界必须保留：不能直接改写结局（只能改因果链）；话本内不能使用该话本世界观之外的力量。
4. 金手指代价必须保留：窥视情节线累积入戏度，入戏太深忘记自我；改写失败被合页吞噬。
5. 主角设定：柳敬亭，末流说书人、祖传无尾残本；核心欲望从「出去补上残本结尾」递进到「查清执笔人、自己拿笔」。
6. 世界观基调：副本是文学题材本身，力量来自叙事学而非斗气魔法；不同副本须呈现对应文体的质感差异。
7. 结构约束：篇幅 91-130 章；配比主线4 / 支线3 / 角色线2 / 暗线2；多副本之间有张弛与递进设计。
