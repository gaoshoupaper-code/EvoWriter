# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## 实验记录

单次实验按实际流程展示运行、评测和进化。左侧轮次从原版开始计数，每批复测或回归递增，候选版本保留独立的改版编号。

运行和进化开始后可进入 Trace 详情，单条评测结束后可查看评分与评语。完整产物和 Harness 改动放在对应详情，返回时恢复实验中的原记录位置。

达标实验在末尾提供审核入口。审核页集中处理发版、加载确认、重试和恢复旧版。按钮沿用服务端提供的操作条件。

界面源码由 `npm run build` 编译。桌面安装包使用 `npm run tauri build` 构建，发布沿用项目的桌面更新流程。
