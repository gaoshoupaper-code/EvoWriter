# worldview-build

世界观维度构建流程（初构 + 增量两种委托）。

## 初构（工作区为空，orchestrator 依赖序第一位）

按系统提示词「一、世界观」的内容规范产出基础世界观框架：

- **最小骨架必须包含**：至少「时代背景 + 核心冲突根源」（其余维度可留占位符，标注"待后续轮次补充"）
- 单文件 `worldview.md`，只写与故事有关的：时代背景、地理空间、社会结构、核心规则（力量体系/社会法则）、历史脉络（仅影响故事的）、核心张力（世界矛盾与对立）
- 先读取 `demand.md` 的设定层（世界观倾向 / 主角设定倾向），保证与需求方向一致

## 增量（扩展中出现新要素时）

- 扩展中出现**新势力**（组织/门派/种族/国家）→ 同步写入 worldview.md
- 扩展中出现**新地点**（城市/区域/地标）→ 同步写入 worldview.md
- 写入最低信息量：名称、与已有势力的关系、在当前事件中的立场

## 注意事项

- 只写 `worldview.md`，不修改 demand.md、人物或故事线文件
- 增量时先读取现有 worldview.md 再补写，不从零重写
- 维度之间保持一致性：引用人物/故事线内容时，确保被引用的内容确实存在
